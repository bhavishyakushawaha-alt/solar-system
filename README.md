# 🪐 Solar System Web Explorer

An interactive web application exploring planets and the solar system, built using **React**, **TypeScript**, and **Vite**.

🌐 **Live Demo:** [View Solar System Web App](https://solar-system-b.netlify.app/)

---

## ✨ Features

- **Interactive Solar System:** Dynamic 3D or visual rendering of planets and celestial bodies.
- **Modern Component Architecture:** Built with modular React components and custom hooks for smooth performance.
- **Type-Safe Development:** Fully written in TypeScript for reliable data handling and logic.
- **Fast Performance:** Bundled with Vite for instant loading and high frame rates.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript
- **Build Tool:** Vite
- **Styling:** CSS
